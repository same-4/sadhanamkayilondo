# 🎮 Sadhanam Kayyilundo?

> **One stupid object. Infinite ways to lose your mind.**

A deliberately useless, rage-inducing webcam game where you use your hand to find and catch one specific object hidden among increasingly unfair duplicates.

**Sadhanam kayyilundo?**  
*"Do you have the thing in your hand?"*

---

## 🧠 What is this?

Sadhanam Kayyilundo? is a browser-based computer-vision game built for the **Useless Projects** contest.

The concept is intentionally simple:

1. The game shows you **which object you need to catch**.
2. Multiple copies of that object appear inside a cluttered scene.
3. Only **one copy is the real sadhanam**.
4. You point at it using your hand.
5. You pinch to grab it.
6. The game progressively makes everything worse.

The project has no practical purpose.

That is literally the purpose.

---

## 🎯 The Objective

Catch the real **sadhanam** before the timer runs out.

Sounds easy.

It isn't.

The game progressively introduces:

- Moving targets
- Identical decoys
- Camouflage
- Transparency
- Evasive behavior
- Inverted controls
- Screen flipping
- Teleportation
- 30+ objects
- Fake feedback
- Increasingly unreasonable difficulty

---

# ✋ How to Play

### Webcam Mode

Allow camera access and use your hand:

| Gesture | Action |
|---|---|
| ✋ Open hand | Start / Resume |
| ☝️ Point | Move the cursor |
| 🤏 Pinch | Grab the object |

The index fingertip acts as your cursor.

The game uses **MediaPipe Hand Landmarker** to track the hand in real time.
